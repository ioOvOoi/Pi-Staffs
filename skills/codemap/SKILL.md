# Codemap（代码地图）

目标：把陌生仓库变成一张可导航的分层地图，而不是把源码搬进上下文。

## 流程

1. 先摸规模与骨架：`ls` 顶层、读 README/包清单/入口文件，确认构建与测试命令。
2. 派 `explorer` 角色做只读侦察（`staffs.run({ role: "explorer", task })`），每层只让它回答「这一层有什么、边界在哪、入口在哪」。
3. 按层级落盘：`docs/codemap/<层>.md`，每层写 4 件事——职责、入口、对外接口、坑（约定/隐式依赖）。
4. 关键路径单独标注：一条数据流从入口到出口，写清经过的文件与函数名。

## 红线

- 地图里只放**指针**（路径 + 符号名）与结论，不贴大段源码。
- 不确定的地方标 `未知`，不要用推测填空。
