# Clonedeps（依赖源码就位）

用途只有一个：当答案在库里而不在文档里时，把那份源码放到本地可读的位置。

## 流程

1. 先定位精确版本：读锁文件（package.json / pnpm-lock.yaml / Cargo.lock），不要用「大概是最新版」。
2. 克隆到忽略目录：`.staffs/deps/<包名>/`，并在 `.gitignore` 里忽略它。
3. 只读你需要的部分：入口文件 → 报错路径涉及的模块 → 相关测试（测试常比文档更能说明契约）。
4. 结论写回任务或笔记，附「文件:行号」，便于复核。
5. 结束时可整体删除该目录，不影响任何构建。

## 红线

- 不改克隆下来的依赖代码（改了也无法持久化，只会误导自己）。
- 不把 `node_modules` 当源码入口——它可能是打包产物或符号链接。
